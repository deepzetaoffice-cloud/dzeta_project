# Task Plans

Approved plans live here as `YYYY-MM-DD-<slug>.md`, using the template in `docs/ai/04-build-sequence.md` §4.

- The **Architect** writes plans; only the **owner** approves them (`Status: APPROVED (owner, date)`).
- The **Implementer** may only touch the files in an approved plan's allowed-files table.
- When a task is finished, set `Status: DONE` and link the PR.

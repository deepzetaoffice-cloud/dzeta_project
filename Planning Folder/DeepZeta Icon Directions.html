00 · Source geometry

What the icons inherit from the logo

Measured directly from the coded logo SVG. These numbers become the rules every icon follows, so the icons and the logo clearly belong together.

  • Corner radius11–14% of the side on every logo pixel. Rule: pixel radius = 12.5% of its size.
  • Size ratio49.4 · 35.6 · 35.2 · 25.5 → about 2 : 1.4 : 1.4 : 1. Signature icons may use a cluster of up to three pixels in this ratio.
  • OrientationPixels are upright squares, never rotated.
  • GradientEach pixel runs light at the top to deep at the bottom. Icon pixels use the exact same stops.
  • Ribbon angleThe Z fold runs at about 35°. Reserved for motion paths and signature icons.
  • Stage coloursPurple = Get Found · Cyan-blue = Win Customers · Royal blue = Run Operations · Light cyan = Get Paid & Keep. (Proposed mapping, not yet approved.)

Note: in this reference drawing the cyan-blue pixel is shifted sideways so all four are visible. The logo file itself is unchanged.

A
Direction A

Zeta Pixel Recommended

Clean frost lines with one glowing logo pixel placed where deepzeta's work happens. At rest the pixel is lit; on hover it tells a tiny story.

Strengths

  • Unmistakably ours: the logo pixel inside every icon
  • Reads clearly from 16px up
  • Lightest code, easiest to extend to 60+ icons

Watch-outs

  • Needs strict discipline: exactly one pixel, always meaningful
  • Calmer at rest than C; the story appears on interaction
B
Direction B

Pixel-Built

Every icon is made entirely of logo-style pixels on a 12×12 grid. Brand-coloured pixels mark the moment of value, and the icon assembles itself in a diagonal wave.

Strengths

  • The strongest visual link to the logo
  • Very memorable at large sizes and in heroes

Watch-outs

  • Blurs below 32px (see size ramp)
  • Curved shapes (lens, bubble, pin) look jagged
  • Many small shapes per icon, so heavier code
  • Reads as "retro 8-bit" if overused
C
Direction C

Glass Gradient

Layered shapes: a brand-colour depth layer, a frosted glass layer and a light sweep on hover. The same logo pixel sits on top.

Strengths

  • The most eye-catching at rest
  • Feels premium and "3D" without 3D files

Watch-outs

  • Glass-and-gradient icons are the 2024–26 trend; many competitors use them
  • Busy when 20+ sit together in a mega-menu
  • Colour layer competes with the pixel at small sizes

05 · Recommendation

Use A as the system, and borrow the best of B and C for the top tier

Direction A for all service and UI icons: it's clear at every size, calm in menus, and the pixel makes every icon unmistakably deepzeta.

For the ~10 signature icons (the 6 Systems and 4 stages), extend A with two borrowed ideas:

  1. From B: a cluster of up to three pixels in the logo's 2 : 1.4 : 1 ratio that assembles on scroll, as a nod to the logo itself.
  2. From C: one light sweep and a soft depth layer, used only at 64px and larger.

This gives one consistent family: simple where people need to scan, rich where you want them to stop and look.
